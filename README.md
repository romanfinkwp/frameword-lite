## Installation

1. Check you version of WordPress, it should be 6.4 or later.
2. Upload the theme.
3. Activate the theme.

To install the development version from this repository, download it as a ZIP (Code > Download ZIP), rename the folder inside to `frameword-lite` and upload it in Appearance > Themes > Add New Theme > Upload Theme.

## Requirements

- WordPress 6.4 or later
- Tested up to WordPress 7.1
- PHP 7.4 or later
